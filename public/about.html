About This Project

Welcome to StudentVault, a full-stack web application designed for students to seamlessly create, manage, and display their academic portfolios and technical credentials.

This project was built as part of a web development curriculum to demonstrate proficiency in modern frontend and backend technologies, database integration, and responsive user interface design.

Technologies Used:

HTML5 & CSS3 JavaScript (ES6+) Node.js Express.js MongoDB & Mongoose
